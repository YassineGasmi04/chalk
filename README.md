# CHALK - the AI pundit that draws on the pitch

> Entry for the Microsoft x Premier League **Inside the Game: Developer Hackathon**
> (challenge: *The Synthetic Match Insights Engine for Premier League Studio*).

TV pundits don't just talk about a moment. They pause the match and draw on it:
an arrow for the run, a circle on the pressing trap, a shaded zone for the gap.
CHALK makes a team of AI agents do that automatically for every key moment of
a live match, checks every claim against the data, and redraws the story
differently for each viewer.

**Data statement:** every club, player and match in this repository is fictional
and generated by code. No real Premier League data or footage is used.

## Pipeline

| Stage | What happens | Where |
|---|---|---|
| **Ingest** | Seeded synthetic match engine streams football-realistic events live (passes, carries, take-ons, pressures, tackles, interceptions, shots, saves, fouls, cards, subs, formation changes) with a 22-player position frame on every event | `chalk/sim/` |
| **Interpret** | Deterministic code turns events into team and player stats, xG, pass difficulty, PPDA, field tilt, top speeds, and a minute-by-minute **Match Pulse** (dominance and control vs chaos) | `chalk/stats/state.py` |
| **Spot** | Plain code decides which moments matter (goals, big chances, red cards, press surges, momentum swings, tactical shifts, record passes and sprints) and attaches the facts, evidence and coordinates | `chalk/stats/moments.py` |
| **Explain** | Agents explain *why* it mattered and turn it into drawings; a VAR agent checks every claim | *(step 3)* |
| **Render** | Live 2D pitch replay in the browser (players and ball interpolated between events, chalk marks for passes, shots and sprints, live stats, moments feed, Match Pulse timeline); animated chalkboard explanations + timed overlay JSON *(step 4)* | `web/` |
| **Personalize** | Analyst / Casual fan / Player-cam modes, favourite club and player, English, French and Arabic | *(step 4)* |

### Design rule: code owns the numbers, AI owns the words

Every number on screen comes from the Interpret layer. Agents may only use
values from a moment's `facts`; the VAR agent rejects any claim that doesn't
match them.

## The synthetic data

`MatchSimulator(seed)` produces a full 90+ minute match from one integer.
Storylines come from a **script of tactical beats** (a high press at 15', a
switch to 4-2-3-1 at 65', a red card at 76'...). Coaching intentions are never
written into the event stream: the Spotter has to discover them from the data,
and the script is saved separately as ground truth so we can test that it does.

Realism across seeds (see `tests/test_engine.py`):

| Metric | CHALK generator | Typical real range |
|---|---|---|
| Events per match | 2,000-2,300 | ~2,000-3,000 |
| Passes | 870-990 | ~800-1,100 |
| Pass accuracy | 81-84% | ~75-88% |
| Shots | 14-24 | ~20-28 |
| Total xG | 1.7-3.4 | ~1.0-3.5 |

**Demo match (seed 4):** Ashvale Rovers 3-2 Kestrel Bay FC. Ashvale's high press
puts them 2-0 up, Kestrel come back to 2-2 with counters and a formation change,
go down to ten men, and concede an 89th-minute winner. Analysis runs at about
11 microseconds per event.

| Scripted beat (ground truth) | Found by the Spotter from data alone |
|---|---|
| 15' Ashvale start a high press | 20' `press_surge` (Ashvale), goals at 26' and 29' |
| 30' Kestrel drop into a low block and counter | 37' `press_surge` (Kestrel), 40' goal |
| 65' Kestrel switch to 4-2-3-1 and press higher | 66' `tactical_shift`, 67' `press_surge` |
| 76' Kestrel red card | 77' `red_card` |
| 78' Ashvale throw everything forward | 80' `momentum_swing`, 84' `press_surge`, 89' winner |

## Run it

Python 3.10+.

```bash
pip install -r requirements.txt
python scripts/generate_match.py          # writes data/match_4*.json(l)
python -m pytest -q                        # tests
python scripts/serve.py                    # opens the replay at http://localhost:8000/web/
```

The replay has two cameras: **Broadcast** (a perspective view from a high
gantry, like a TV tactics camera) and **Tactical** (flat, top-down). Switching
between them animates the camera move.

In the replay: Space plays and pauses, the arrow keys skip 15 seconds, the Match
Pulse ribbon is a scrubber, and selecting a key moment jumps to just before it.

## Project layout

```
chalk/
  sim/teams.py       fictional clubs, squads, formations
  sim/engine.py      seeded match simulator + storyline script
  stats/metrics.py   xG, pass difficulty, lines broken, progressive passes
  stats/state.py     live stats + Match Pulse
  stats/moments.py   the Spotter: moments with facts, evidence, geometry
scripts/generate_match.py
scripts/serve.py     local web server for the replay
web/                 replay UI: index.html, style.css, pitch.js (renderer), app.js
tests/
data/                generated match files
```
